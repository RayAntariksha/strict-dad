# strict-dad

> "The digital parent your focus needs."

`strict-dad` is a desktop application designed to help you stay focused by syncing your daily calendar with active application blocking. Plan your day out hour-by-hour, select which distractions to keep away during specific windows, and let `strict-dad` enforce your discipline.

Built with performance and reliability in mind by **RayAntariksha**.

---

## 🚀 How It Works

1. **Launch & View**: Open the app to view your day structured in a clean, calendar-style column view.
2. **Schedule a Session**: Click on any empty time slot in the day column (just like Google Calendar) to create a new session.
3. **Select Blocked Apps**: A popup modal will appear letting you choose which installed applications you want to restrict during that specific timeframe.
4. **Automatic Enforcement**: When the scheduled time arrives, `strict-dad` automatically blocks access to those applications until your session ends.

---

## 🛠️ Tech Stack

`strict-dad` is crafted using a modern, lightweight, and high-performance stack:
* **Core & System Control**: [Rust](https://www.rust-lang.org/) (for robust system-level monitoring and app blocking)
* **Desktop Framework**: [Tauri](https://tauri.app/) (for a secure, native desktop experience)
* **Frontend**: [Vue.js](https://vuejs.org/) (for a reactive, intuitive calendar interface)
